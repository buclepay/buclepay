# Contributing

Thanks for helping. Issues and pull requests are welcome for the SDKs (`sdk/`) and the docs.

- **Security problems:** never in a public issue. See [SECURITY.md](SECURITY.md).
- Run the tests before opening a PR: `node --test` in `sdk/node`, `flutter test` in `sdk/flutter`, `npm test` in `examples/node-express`.
- By contributing you agree that your contribution is licensed under MIT.
